## Site settings

Edit the site title, URL, and baseurl in `_config.yml`.

### Repository-specific URLs

For GitHub Pages under a project repository, set `baseurl` to the repository name prefixed with `/`.

## Navigation

Edit `_data/navigation.yml` to add menu items and nested children.

### Active page

The selected navigation entry is highlighted with a red left border.

## Table of contents

The right-side TOC is generated from Markdown headings.

### ScrollSpy

A scroll listener highlights the current heading, and the TOC scrolls to reveal its selected entry.
