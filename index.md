## Introduction

This is a reusable Minimal Mistakes documentation website with hierarchical left navigation and a sticky right-hand table of contents.

### Navigation

Select a page in the left sidebar to change documents.

## ScrollSpy

The right sidebar highlights the current heading while you scroll.

### Active section

The red border follows the section currently being read.

## Customization

Edit `_config.yml`, `_data/navigation.yml`, and the Markdown pages to use this template in another repository.
